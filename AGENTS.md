# Инструкции проекта

## Проект
REST API редакции новостного издания, вариант 27.

## Архитектура
- controllers — обработка HTTP-запросов и формирование ответов.
- services — бизнес-логика и обработка связей между сущностями.
- repositories — хранение и получение данных.
- models — бизнес-сущности.
- facades — упрощённые объекты запросов из двух полей.
- factories — создание бизнес-сущностей.

## Правила
- Бизнес-сущности должны быть final.
- Не объявлять явные конструкторы в бизнес-сущностях.
- Использовать @Cumponent для новых Spring-бинов, сохраняя профильные аннотации.
- Время проверки и дата создания выпуска задаются сервером.
- При удалении связанных сущностей не оставлять недействительные ссылки.
- Соблюдать HTTP-коды, предусмотренные заданием.
