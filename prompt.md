# Контекст проекта

Реализовать REST API редакции новостного издания по варианту 27.

## Сущности
- EditorialSection — рубрика.
- Article — статья.
- EditorialReview — редакторская проверка.
- EditionIssue — выпуск издания.
- User — пользователь.

## Требования
- CRUD-операции через REST.
- Архитектурное разделение на контроллеры, сервисы и репозитории.
- Бизнес-сущности final, без явно объявленных конструкторов.
- Создание бизнес-сущностей через специализированные фабрики.
- Двухполевые фасады для запросов контроллеров.
- Собственная аннотация @Cumponent.
- Отдельный контроллер, возвращающий статический HTML для POST и PUT.
- Серверное время для операций, где требуется текущая дата или время.
- Корректная обработка связей и удалений.
- Настройки в application.yml для приложения и тестов.
